# Workers — GATED

This directory is intentionally empty.

Worker task files will be created here by Directors once the design foundation is locked.

## Activation Criteria

Workers are gated until ALL of the following are true:

1. Design System Director confirms tokens populated in `/design-tokens/*.json`
2. Chief of Staff verifies the lock
3. `cerenetics-design-system` skill `_status` fields are removed
4. `cerenetics-component-patterns` skill visual specs are populated

**Do not create worker task files until these conditions are met.**
